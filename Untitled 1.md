|---|---|---|---|
|**2013**|**Pseudo-Label** (Precursor)|Proposed pseudo-labeling, implicitly performing entropy minimization and confidence filtering (fixed threshold τ).||
|**2020**|**FixMatch** (Baseline)|Popularised weak-to-strong consistency combined with a fixed confidence threshold (τ=0.95) for filtering pseudo-labels. This fixed constraint demonstrated the fundamental limitations that adaptive thresholds later sought to address.||
|**2021**|**FlexMatch**|Introduced **Curriculum Pseudo Labeling (CPL)**, a curriculum learning approach that dynamically adjusts class-specific thresholds. The threshold Tt​(c) is derived from a normalized estimate (βt​(c)) of the number of confident samples observed for class c, allowing easier classes to adopt stricter thresholds sooner.||
|**2021**|**Adsh**|Proposed obtaining adaptive thresholds by explicitly optimizing the number of pseudo-labels for each class within the SSL objective for handling imbalanced SSL, still relying on a user-predefined threshold.||
|**2021**|**SemiFed**|Adopted the concept of multiple models agreeing on a label (federated pseudo-labeling) _before_ applying a predetermined, potentially dynamically adjusted threshold (γt​). This applied pseudo-labeling specifically in a Federated Learning (FL) context.||
|**2022**|**CBAFed**|Introduced **Class Balanced Adaptive Pseudo Labeling** for Federated Semi-Supervised Learning (FSSL) under Non-IID data. It adjusts pseudo-labeling thresholds based on the empirical distribution of _all_ training data (labeled and unlabeled) in local clients, aiming to set a high lower bound for scarce classes to prevent noise intrusion.||
|**2022**|**RSCFed**|Focused on model aggregation robustness in FSSL, but the core local component (Fed-Consist, implicitly) relied on consistency and pseudo-labeling, making it susceptible to the underlying threshold limitations that motivate adaptive strategies.||
|**2023**|**FreeMatch**|Proposed a **Self-Adaptive Thresholding (SAT)** technique that estimates both global (dataset-specific) and local (class-specific) thresholds using the Exponential Moving Average (EMA) of unlabeled data confidence. This approach removes the reliance on manually setting fixed global thresholds entirely, making the adjustment fully self-adaptive.||
|**2024**|**ENCORE**|Focused on Semantic Segmentation, ENCORE (Ensemble-of-Confidence Reinforcement) proposed a dynamic feedback-driven thresholding strategy. It estimates **Class-Aware Confidence (CAC)** and uses **Adaptive Confidence Thresholding (ACT)** based on the model's performance (Dice metric) on labeled data, eliminating the need for manual tuning of thresholds.||
