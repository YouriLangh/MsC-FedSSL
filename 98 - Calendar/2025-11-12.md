## Two practical retention variants

### A) Per-round fixed buffer (CBAFed-style, minimal)

- Build once **at the start of each local round**; use for all local epochs; discard after upload.
    
- Good default; tiny code change; stabilizes targets within a round.
    

**Algorithm (client k, round r)**

1. Reset `buffer = {}`.
    
2. One pass over unlabeled set:
    
    - compute weak logits → `ŷ`, `conf`
        
    - require **FixMatch gate**: `conf ≥ τ(c)` and `agree(weak, strong)`
        
    - store: `buffer[idx] = { y_hat=ŷ, conf=conf, cls=c }`
        
3. For each epoch:
    
    - train labeled minibatch normally (`L_s`)
        
    - iterate a minibatch of **retained indices**:
        
        - sample **strong** aug, compute `CE(y_hat, f(x_strong))`, add to `λ * L_u`
            
4. Discard `buffer` at end of round.
    

**Optional guards**

- **Per-class top-k** cap (e.g., 64) to avoid head-class domination.
    
- Balance retained sampling across classes during the epoch.

## ✍️ Thesis wording (you can paste this)

> _We adopt a per-class adaptive thresholding mechanism, where each class maintains an exponentially weighted moving average (EMA) of its pseudo-label confidence. The threshold for class (c) becomes ( \tau_t(c) = \tau_{base} \cdot EMA(conf_c) ). Thus, classes that are under-represented or harder to learn receive a lower threshold, enabling more pseudo-labels to be generated for them, addressing class imbalance in Non-IID FSSL._
