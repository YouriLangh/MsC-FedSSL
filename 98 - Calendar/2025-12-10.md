
# **1. Why FixMatch + FedAvg fails (core idea)**

### **FixMatch depends on stable, meaningful logits.**

It selects pseudo-labels based on confidence thresholds.

### **Federated learning destroys that stability.**

Under non-IID data:

- Each client learns **different, biased representations**
    
- These local models **drift apart**
    
- FedAvg **averages incompatible local optima**
    

The result:

- The **global logits fluctuate unpredictably** across rounds
    
- Confidence distributions become **incoherent**
    
- Early pseudo-labels are **noisy and biased**
    
- Representation learning **never stabilizes**, especially for minority classes
    

So the basic failure mode is:

> **Local bias → representational drift → FedAvg amplifies drift → global logits become unreliable → pseudo-labeling collapses.**

FixMatch is fundamentally built on **logit confidence**, and FedAvg makes those confidences **meaningless**.

# **2. Why your lightweight extensions (ADSH + STM) don’t help**

The extensions assume something that is not true in FSSL:

> **That the logits are reliable enough for thresholding or pseudo-label retention to work.**

### **ADSH (adaptive thresholds)** fails because:

- It adapts thresholds using **local**, highly skewed confidence statistics
    
- But FedAvg **reshuffles the logits every round**, so thresholds no longer match the global model
    
- Majority classes dominate all confidence buckets → **thresholds reinforce local bias**
    

**Adaptive thresholding cannot fix the fact that the underlying logits are unstable.**

---

### **STM (short-term retention)** fails because:

- Retained pseudo-labels rely on **consistency of logits** across rounds
    
- But FedAvg causes the global model to **change too much** between rounds
    
- So retained labels quickly become **outdated or wrong**
    

STM reduces variance but **does not improve representation quality**.

---

**In one sentence:**

> **FixMatch+FedAvg fails because non-IID data causes locally biased models whose inconsistent representations are averaged into globally unstable logits; since both adaptive thresholding and pseudo-label retention depend on meaningful logits, neither extension can correct this representational collapse.**
